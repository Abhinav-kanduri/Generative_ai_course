## Foundation Week 1

Foundation Week 1 builds the algorithmic base for modern AI systems.

- **Algorithm Insights**
  - Learn how to choose an algorithm by first identifying the problem type.

- **Machine Learning Algorithms**
  - Compare supervised, unsupervised, semi-supervised, reinforcement, ensemble, anomaly, and time-series methods.

- **Natural Language Processing**
  - Understand preprocessing, embeddings, classification, entity extraction, semantic search, summarization, and RAG.

- **Deep Learning**
  - Review neural networks, CNNs, RNNs, Transformers, GANs, diffusion models, graph networks, and multimodal models.

- **Transformers**
  - Learn self-attention, encoder/decoder blocks, masked attention, and why Transformers power modern LLMs.

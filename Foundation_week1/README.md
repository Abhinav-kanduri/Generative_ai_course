## Quick Decision Map

- Predict a number: use regression.
- Predict a class: use classification.
- Group similar records: use clustering.
- Detect unusual behavior: use anomaly detection.
- Understand text: use NLP.
- Generate text: use decoder-only Transformers or LLMs.
- Summarize or translate: use encoder-decoder Transformers.
- Search by meaning: use embeddings and semantic search.
- Answer from documents: use Retrieval Augmented Generation.

## Interview Tip

Start every answer with:

> The business problem is a regression, classification, clustering, anomaly detection, text understanding, generation, or retrieval problem.

Then explain why the selected algorithm family fits that problem.
